Small uppercase pill for route states and tags (e.g. "FASTEST", "QUIET", "ALERT").

```jsx
<Badge tone="mint">Quiet route</Badge>
<Badge tone="lime">Preference match</Badge>
<Badge tone="orchid" solid>Closing soon</Badge>
```

Tones: `neutral`, `accent`, `mint`, `lime`, `liliac`, `orchid`. `solid` fills with the tone color.
