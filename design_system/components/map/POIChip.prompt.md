A place marker on the map — uppercase mono in a frosted capsule; selecting it expands the capsule into an outlined Cobalt box with a meta line.

```jsx
<POIChip label="Riverside Park" />
<POIChip label="Old Town Gate" meta="320 m · left" selected />
<POIChip label="Late pharmacy" alert />
```

Props: `label`, `meta` (shown when selected), `selected`, `alert` (Orchid specialized POI), `icon`, `onClick`.
